# Every grade of the rank ladder on a unit, one grid a side (2026-10-21): seats 0-4 are allied
# and are the grid's columns, each row is one template, and grade = 5 x row + seat, so a side's
# grid reads row by row from grade 0 (no insignia) at top left. A grade lands on every matching
# unit of a seat, which is why each row is its own template. Seat 5 is the lone enemy that keeps
# the match open. Everything drives 300 east from scenario frame 120 (logic 240), and
# Cinema/rankladder.txt shoots each grid in the first second of that drive, before the higher
# grades' speed pulls their column ahead.
#
#   generals.exe -win -borderless -xres 1920 -yres 1080 -msaa 0 -quickstart -noshellmap -observer
#     -multiInstance -fps 120 -noFPSLimit -particlecap 2500
#     -map "Maps\Twilight Flame\Twilight Flame.map" -autoskirmish 6 -takeover
#     -team 0 0 -team 1 0 -team 2 0 -team 3 0 -team 4 0 -team 5 1 -seed 1
#     -scenario rankladder -cinema rankladder -video 260 340 rankladder -maxframes 360
#
# -video is there for its clock: while a range is set the shot list runs on the logic frame, not
# the wall clock, so a slow load cannot fire every shot before the units exist.
#
# Columns x 3330 + 70 x seat, rows 45 apart: USA y 3640-3865 (29 grades, 0-28), China 3920-4055
# (20, 0-19), GLA 4110-4290 (21, 0-20). Grade 0 is unranked on every side and wears nothing. South of y 3620 is cliff from x 3300 to 3440.
